# data/

Everything in this folder except this file and `.gitkeep` is git-ignored on purpose.

It holds the local SQLite database, raw API responses (`raw/`), and any Power Almanac CSV imports or exports. These are third-party contact lists about real people.

- Do not commit them, paste them into issues, or share them outside what the Power Almanac license allows. Check that license before storing or redistributing the data.
- Keep a backup of `data/yellowbook.sqlite` somewhere private; it is the only copy of accepted findings and review decisions.
